# HotelsUjjain.in

**HOTELS UJJAIN: Find Your Right Stay.**
A mobile-first hotel discovery guide for Ujjain, Madhya Pradesh. It is *not* an online travel agency: no bookings, payments or inventory. Visitors discover places to stay, then contact hotels directly (WhatsApp) or go to booking partners (affiliate links). Revenue comes from affiliate commissions, labelled paid listings, direct enquiries and local advertising.

> **Status: Task 01 complete (foundation + homepage prototype).** Hotel listings shown are labelled **samples**. Indexing is switched off until launch.

---

## Quick start

Requirements: **Node 18+** (no npm packages needed). Python 3 + Pillow only for the image pipeline.

```bash
npm run dev          # build into dist/ and serve at http://localhost:4173
npm run build        # build only
npm run qa           # strict build + static QA (links, meta, headings, alt text, JSON-LD)
node scripts/qa-browser.cjs    # Playwright: layouts, console errors, nav, search, a11y (optional)
```

## How the build works

`scripts/build.mjs` (≈ 350 lines, no dependencies):

1. Loads `data/*.json` (file names become camelCase keys, e.g. `sample-hotels.json` → `data.sampleHotels`).
2. Renders each `src/pages/**/*.html` through `src/layouts/base.html`. Pretty URLs: `about.html` → `/about/`.
3. Publishes a **noindex "coming soon" page** for every planned URL in categories/areas/guides/planned-pages that has no real page yet. This is why there are no broken links.
4. Inlines CSS imports and minifies, copies assets, and adds `?v=<hash>` to CSS/JS URLs for long-term caching.
5. Writes `sitemap.xml` (real pages only) and `robots.txt`, and injects CSP hashes into `_headers`.
6. Warns on missing or long titles and descriptions, duplicates, and undefined template variables (`--strict` fails the build).

### Page front matter and template syntax

```html
---
title: Budget Hotels in Ujjain | HotelsUjjain.in
description: Up to 160 characters, unique per page.
noindex: false            # optional
ogImage: /assets/images/og/budget.jpg   # optional
---
<h1>{{ page.title }}</h1>            <!-- escaped value -->
{{{ page.structuredData }}}           <!-- raw value -->
{{> search-form }}                    <!-- component: src/components/search-form.mjs -->
```

## Adding photos

1. Put originals in `assets-src/photos/<key>.jpg` (keys and licence details in `manifest.json`).
2. Check each photo and its alt text; set `"altVerified": true`.
3. `python3 scripts/images.py` → AVIF/WebP/JPEG at 480–2000 px + `data/photos.json`.
4. `npm run build`. The hero, area cards, guide cards and the photo credits page update automatically.

## Content rules

Never invent hotel names, prices, ratings, amenities, availability or reviews. Sample content must be visibly labelled. Paid placements are labelled **Featured · Paid**. Hotel photos only with the owner's written permission. See `docs/DESIGN-SYSTEM.md` §7.
