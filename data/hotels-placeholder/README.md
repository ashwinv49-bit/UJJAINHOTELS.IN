# Placeholder hotel records: NOT REAL HOTELS

These records exist only to test the hotel profile, directory and filters in **local design builds**.

- Every record has `"placeholder": true`, a name starting with `PLACEHOLDER`, phone `+910000000000`, and no photos, coordinates or distances.
- They are **never loaded on Netlify** (live site or Deploy Previews), and the build fails if any placeholder text reaches a Netlify build.
- Statuses cover the workflow: A/B/C `verified` (A is featured, with an affiliate link to a disabled partner), D `draft`, E `contacted`.

Do not copy values from these files into real records.
